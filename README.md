# 午餐錢小幫手 🌿

> 團體訂餐的對帳工具，輸入每人餐費後自動計算、扣款並寫入 Google Sheets。

**使用網址：** https://timelesspaperart003.github.io/lunch-payment/

---

## 使用方式（給打帳者）

1. 打開網址
2. 選擇姓名，輸入密碼登入
3. 填入訂單標題、打單日期、外送費、優惠折扣
4. 逐一新增訂餐人員與金額
5. 確認本單總覽無誤後按「送出對帳」
6. 系統自動扣款並寫入金流紀錄表

---

## 計算邏輯

- **實際扣款** = 餐費 − 優惠折扣分攤 + 外送費分攤
- **服務費** = 一般 2 元／低額逾期者 12 元
- 服務費從成員扣除後，轉入打帳者餘額

## 管理員設定（第一次部署）

### 1. Google Sheets 結構

主名單表欄位（A～K）：

| 欄 | 欄位名稱 |
|----|---------|
| A | 姓名 |
| B | LINE_ID |
| C | 餘額 |
| D | 上次通知日 |
| E | 註冊時間 |
| F | 角色 |
| G | 共用錢包歸戶 |
| H | 低額逾期狀態 |
| I | 低額開始日 |
| J | 最近提醒日 |
| K | 打帳者（兼密碼）|

> K 欄填入名字的人才能登入，該名字即為系統密碼。

### 2. Apps Script 部署

1. 在 Google Sheet 開啟 **擴充功能 > Apps Script**
2. 新增檔案，貼上 `Code.gs` 的內容
3. **部署 > 新增部署作業**
   - 類型：網頁應用程式
   - 執行身分：我
   - 誰可以存取：任何人
4. 複製產生的網址，填入 `index.html` 的 `CFG.SCRIPT_URL`

### 3. 更新程式碼

直接在 GitHub 編輯 `index.html` 並 commit，Pages 會自動重新部署（約 1 分鐘生效）。
